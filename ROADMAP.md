# Roadmap

This roadmap shows the planned direction for Shinobi Guard.

## Short term

- Polish blocking animations
- Improve first-person defense pose
- Tune third-person defense visuals
- Add more debug information for combat detection

## Medium term

- Expand Naruto Mod compatibility patterns
- Refine elemental balance values
- Improve parry feedback and impact effects
- Add better HUD clarity for defense states

## Long term

- Support more external combat mods
- Add optional visual themes
- Improve configurable keybind categories
- Add more polished release packaging for public builds

## Ideas under consideration

- Better sound variation for parry
- More cinematic perfect parry effect
- Extra HUD glow on successful parry
- Optional screen shake for perfect timing
