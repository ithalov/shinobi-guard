# FAQ

## What is Shinobi Guard?

Shinobi Guard is a Minecraft Forge 1.12.2 mod centered on defense, directional blocking, and perfect parry.

## Does blocking still reduce damage?

Yes. Normal defense reduces damage instead of fully canceling it.

## Does perfect parry cancel the hit?

Yes. A successful perfect parry cancels the incoming damage.

## Is this multiplayer compatible?

Yes. Defense state and feedback are synchronized between client and server.

## Can I reload config without restarting the game?

Yes. The mod includes a reload command for the defense configuration.

## Is the source code public?

No. This repository is meant for public presentation, releases, and documentation only.

## What version of Minecraft does it target?

Minecraft Forge 1.12.2.

## Will it work with the Naruto Mod?

The mod includes a compatibility layer that recognizes several Naruto damage types and elemental patterns.

## Where are the releases?

Releases should be published in GitHub Releases.
