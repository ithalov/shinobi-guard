# Shinobi Guard

Shinobi Guard is a Minecraft Forge 1.12.2 mod focused on directional defense, perfect parry, visual feedback, and combat compatibility.

## Features

- Directional blocking
- Perfect parry with zero damage
- Defense HUD
- Client-side feedback and particles
- Multiplayer synchronization
- Compatibility with external damage systems
- Configurable defense values

## How it works

The player can raise defense with a dedicated key.
If the timing is right, the attack is fully canceled by a perfect parry.
If the timing is late or the attack is only blocked, damage is reduced instead of being fully negated.

## Compatibility

- Minecraft Forge 1.12.2
- Java 8
- Multiplayer supported
