# Shinobi Guard

Shinobi Guard is a Minecraft Forge 1.12.2 mod focused on directional defense, perfect parry, visual feedback, and multiplayer-friendly combat.

## Features

- Directional blocking
- Perfect parry with zero damage
- Defense HUD
- Client-side particles and hit feedback
- Multiplayer synchronization
- Configurable defense values
- Compatibility hooks for external damage systems

## How it works

The player raises defense with a dedicated key.
If the timing is right, a perfect parry cancels the attack completely.
If the timing is late, the attack is reduced instead of being fully negated.
